Rust 与系统接口

蓝河内核用 Rust 构建核心能力，同时提供 POSIX 风格的接口，支持与 C 代码和既有驱动协作。这让应用层、系统接口与硬件适配可以分工实现，而不必全部使用同一种语言。

在支持的运行环境中，Rust 应用可以使用标准库提供的文件、线程等接口。代码看起来接近普通 Rust 程序，但最终仍要经过运行库和内核，才能访问设备上的真实资源。

内核本身与普通应用不同。它需要在调度器、文件系统甚至堆尚未准备好时启动，不能随意依赖已经完整初始化的系统环境。因此，内核与应用的依赖和启动顺序需要清晰区分。

系统调用是跨越应用与内核服务边界的入口。蓝河内核的相关实现支持直接调用和软中断方式；具体选择由构建配置决定，调用方不必为每一种方式重写业务流程。

标准接口并不意味着所有桌面功能都能原样使用。文件路径、可用驱动、线程资源和网络能力，仍取决于目标板、内核配置及适配进度。移植应用时，应先验证实际需要的那一组接口。
